# Glutinum.Web

Fable bindings for the DOM and the web APIs, generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@types/web`](https://www.npmjs.com/package/@types/web).

The bindings live in the `Glutinum.Web` module. The globals (`document`, `window`, `fetch`, `setTimeout`, the constructors) are static members of `Glutinum.Web.Exports`.

```fsharp
open Glutinum
open type Glutinum.Web.Exports

document.title <- "Hello"

let button = document.createElement "button"
button.textContent <- "Click me"

button.addEventListener ("click", fun (event: Web.Event) -> console.log event.``type``)

document.body.appendChild button |> ignore

for paragraph in document.querySelectorAll "p" do
    console.log paragraph.textContent
```

A binding generated by Glutinum for a package using the DOM types references this package: add it next to the binding.

The file `Glutinum.Web.fs` is generated by `./build.sh bindings` in the repository, do not edit it.
